# MID AI — اسکریپت میدلین دوتا ۲ (Bot Scripting API)

هوش مصنوعی میدلین برای چهار هیرو، نوشته‌شده روی **API رسمی Bot Scripting** والو
(همان چیزی که در لابی‌های بات و کاستم‌گیم کار می‌کند).

| هیرو | فایل مغز |
|---|---|
| Ember Spirit | `heroes/ember_spirit.lua` |
| Puck | `heroes/puck.lua` |
| Earth Spirit | `heroes/earth_spirit.lua` |
| Storm Spirit | `heroes/storm_spirit.lua` |

---

## ۱) نصب

فایل‌ها را در این مسیر کپی کن:

```
<Steam>/steamapps/common/dota 2 beta/game/dota/scripts/vscripts/bots/
```

ساختار نهایی:

```
bots/
├── mid_ai_core.lua           # هسته (لست‌هیت، دنای، لاین، آیتم، نبرد)
├── mid_ai_settings.lua       # منوی تنظیمات
├── heroes/
│   ├── ember_spirit.lua
│   ├── puck.lua
│   ├── earth_spirit.lua
│   └── storm_spirit.lua
├── hero_ember_spirit.lua     # ورودی‌های بازی
├── hero_puck.lua
├── hero_earth_spirit.lua
└── hero_storm_spirit.lua
```

سپس یک لابی بسازی، بات اضافه کن و گزینه‌ی **Local Dev Scripts** را فعال کن.
هر باتی که یکی از این چهار هیرو را بگیرد، اسکریپت خودش را می‌گیرد.

---

## ۲) منوی تنظیمات و کلیدها

همه‌ی گزینه‌ها در `mid_ai_settings.lua` هستند (روشن/خاموش کردن لست‌هیت، دنای،
هرس، اسکیل‌ها، آیتم‌ها، رون، گنک، پوش، میزان تهاجم و ...).

**اعمال تغییرات حین بازی، با یک کلید:**

```
bind "F5" "dota_bot_reload_scripts"
```

فایل تنظیمات را ذخیره کن → `F5` را بزن → تنظیمات جدید بدون ری‌استارت اعمال می‌شود.

اگر محیط اجرای تو کانسول‌ور می‌سازد، این نام‌ها بدون ری‌لود هم خوانده می‌شوند و
اولویت بالاتری نسبت به فایل دارند:

```
mid_ai_master   mid_ai_lasthit  mid_ai_deny   mid_ai_harass
mid_ai_abilities mid_ai_items   mid_ai_runes  mid_ai_gank
mid_ai_push     mid_ai_debug    mid_ai_aggression
```

مثال: `bind "F8" "toggle mid_ai_harass 0 1"`

## ۳) چه چیزهایی پیاده شده است

**موتور لست‌هیت / دنای (دقیق‌ترین بخش اسکریپت)**
- پیش‌بینی HP کریپ در «لحظه‌ی اصابت» ضربه، نه لحظه‌ی فعلی
- محاسبه‌ی زمان windup بر اساس اتک‌اسپید + زمان سفر پرتابه بر اساس فاصله
- کسر کردن پرتابه‌های در حال پرواز روی همان کریپ (تا دوبار نزنیم)
- کسر کردن DPS کریپ‌های ملی خودی و حریف
- استفاده از رول پایین دمیج (`LASTHIT_SAFETY`) تا لست‌هیت «تقریبا» از دست نرود
- انتخاب بین لست‌هیت و دنای بر اساس ارزش (کریپ رنج/سیج ارزش دنای بالاتر)
- حالت `soon` / `step`: اگر کریپ چند لحظه دیگر قابل کشتن است، ضربه هدر نمی‌رود
  و بات فقط موقعیت می‌گیرد

**کنترل لاین**
- محاسبه‌ی نقطه‌ی برخورد موج‌ها و تعادل لاین
- کشیدن ارگ کریپ‌ها با ضربه به حریف وقتی لاین زیادی جلو رفته
- ایستادن در «لبه‌ی برد حمله، سمت خانه» و عقب‌نشینی خودکار از برد تاور
- Orb Walk: کنسل کردن backswing بعد از هر ضربه و ریپوزیشن

**نبرد و بقا**
- تخمین دمیج ورودی (`GetEstimatedDamageToTarget`) و عقب‌نشینی قبل از مرگ
- BKB، گلیمر، گوست، بلید‌میل، فورس‌استاف، بلینک، شدوبلید به‌صورت خودکار
- انتخاب هدف بر اساس (تهدید ÷ جان مؤثر) + جان کم + فاصله
- دیفنس با TP، گنک، پوش، روشان، بای‌بک اضطراری

**اقتصاد**
- خرید پویا بر اساس هیرو + ترکیب تیم حریف (سنتری/داست، BKB، مقاومت جادویی)
- لِوِل‌آپ با ترتیب دقیق حرفه‌ای برای هر هیرو + انتخاب تلنت

**اختصاصی هر هیرو**
- **Ember**: Flame Guard قبل از ترید، Sleight of Fist برای هرس بدون ریسک و
  گرفتن لست‌هیت، همیشه یک Fire Remnant عقب برای فرار
- **Puck**: Phase Shift خودکار روی پرتابه‌های در حال پرواز و ضربه‌ی تاور،
  Illusory Orb + Ethereal Jaunt برای فرار/ورود، Dream Coil فقط وقتی ارزش دارد
- **Earth Spirit**: مدیریت شارژ سنگ، هرس با Stone + Boulder Smash از فاصله،
  کمبوی Stone → Smash → Roll → Magnetize → Grip
- **Storm**: محاسبه‌ی دقیق هزینه‌ی Ball Lightning، نگه‌داشتن مانای فرار،
  الگوی Remnant + ضربه‌ی Overload برای هرس

## ۴) نکات مهم

- این اسکریپت روی **API رسمی بات‌ها** کار می‌کند: لابی با بات، کاستم‌گیم و
  تمرین. در بازی‌های آنلاین/رتبه‌ای اجرا نمی‌شود.
- کیفیت بازی بات به شدت به تنظیمات `HARASS_AGGRESSION` و `LASTHIT_SAFETY`
  وابسته است؛ اگر لست‌هیت از دست می‌رود `LASTHIT_SAFETY` را به ۰.۹۰ کاهش بده.
- اگر پچ جدید نام یک اسکیل یا آیتم را عوض کند، همان مورد به‌طور امن نادیده
  گرفته می‌شود (همه‌ی فراخوانی‌ها در لایه‌ی محافظت‌شده هستند) — فقط کافی است
  نام جدید را در فایل مغز هیرو به‌روزرسانی کنی.
