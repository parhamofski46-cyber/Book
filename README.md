# زرّین — قالب سایت طلا و جواهرفروشی

**سایت کامل، راست‌به‌چپ و فارسی برای طلافروشی، با نمایشگر سه‌بعدی واقعی (WebGL) و بدون هیچ وابستگی بیرونی.**

</div>

---

## این پروژه چیست

یک سایت فروشگاهی کامل و آماده‌ی انتشار برای گالری طلا و جواهر. همه چیز ایستا (HTML/CSS/JS) است، بنابراین
روی GitHub Pages، Netlify، Vercel، لیارا، ابرآروان یا هر هاست ساده‌ای بدون سرور و بدون مرحله‌ی build اجرا می‌شود.

نکته‌ی اصلی این است که **هیچ کتابخانه‌ی بیرونی، هیچ CDN و هیچ فایل تصویری باینری در پروژه وجود ندارد**.
موتور سه‌بعدی، تصویرسازی قطعات و کل رابط کاربری از صفر نوشته شده‌اند. یعنی:

- سایت در شبکه‌های فیلترشده یا کند هم کامل بالا می‌آید.
- هیچ‌وقت به خاطر از دسترس خارج شدن یک CDN نمی‌شکند.
- کل حجم صفحه‌ی نخست، بدون فونت، حدود ۲۰۰ کیلوبایت است.

## امکانات

**نمایش سه‌بعدی (`assets/js/jewel3d.js` + `assets/js/gl.js`)**
- موتور WebGL2 دست‌نویس: ریاضیات ماتریسی، سازنده‌های هندسه و شیدرها همگی در همین مخزن.
- حلقه‌ی تک‌نگین با هندسه‌ی واقعی: بند کامفورت‌فیت، سبد، دو شانه‌ی کاتدرال، شش چنگه و نگین تراش برلیان با نسبت‌های تولکوفسکی.
- فلز با مدل PBR و محیط استودیویی تحلیلی (بدون فایل HDR).
- نگین با شبیه‌سازی شکست نور، دو بازتاب داخلی و **پاشندگی رنگی** — همان چیزی که به الماس «آتش» می‌دهد.
- ضدلبه‌ی چندنمونه‌ای (MSAA) و بلوم دومرحله‌ای.
- چرخش با کشیدن انگشت یا ماوس، اینرسی، چرخش خودکار و پارالاکس با حرکت نشانگر.
- توقف خودکار رندر وقتی از دید خارج می‌شود، سقف تعداد پیکسل و مدیریت از دست رفتن context.
- اگر مرورگر WebGL2 نداشته باشد، خودکار به تصویر برداری جایگزین سوییچ می‌کند.

**فروشگاه**
- ۱۸ محصول نمونه در ۸ دسته، با فیلتر دسته، نگین، رنگ طلا، سقف قیمت، جست‌وجو و پنج حالت مرتب‌سازی.
- سبد خرید با `localStorage`، کشوی کناری، تغییر تعداد و محاسبه‌ی هزینه‌ی ارسال.
- علاقه‌مندی‌ها، نمایش سریع (Quick View)، جست‌وجوی سراسری با `Ctrl/⌘ + K`.
- صفحه‌ی محصول با نمایشگر سه‌بعدی هماهنگ با همان قطعه، انتخاب رنگ طلا، جدول سایز و داده‌ی ساختاریافته‌ی Schema.org.

**ابزارهای مخصوص بازار ایران**
- نوار نرخ لحظه‌ای طلا، سکه و مثقال.
- ماشین‌حساب قیمت با **فرمول واقعی بازار**: `(وزن × نرخ گرم) + اجرت + سود + مالیات بر ارزش افزوده`،
  با این نکته‌ی مهم که مالیات فقط به اجرت و سود تعلق می‌گیرد نه به ارزش طلای خام.
- تفکیک کامل قیمت روی هر محصول، دقیقاً مثل فاکتور رسمی.
- مبدل سایز انگشتر (ایران / US / UK / قطر).

**رابط کاربری**
- کاملاً راست‌به‌چپ و فارسی، با اعداد فارسی در سراسر سایت.
- دو پوسته‌ی تیره و روشن با ذخیره‌ی انتخاب کاربر.
- پیش‌بارگذار، نشانگر سفارشی، کارت‌های سه‌بعدی با افکت تیلت، ظهور تدریجی هنگام اسکرول، نوار پیشرفت.
- واکنش‌گرا از ۳۲۰ پیکسل تا نمایشگرهای فوق‌عریض.
- احترام کامل به `prefers-reduced-motion` و کارکرد صحیح بدون جاوااسکریپت.

## اجرا

```bash
git clone https://github.com/parhamofski46-cyber/book.git
cd book
npx http-server -p 8080     # یا: python3 -m http.server 8080
```

سپس <http://localhost:8080> را باز کنید.

> فایل‌ها ماژول ES هستند، بنابراین باید از طریق یک سرور باز شوند. باز کردن مستقیم `index.html`
> با `file://` به دلیل قوانین CORS مرورگر کار نمی‌کند.

## انتشار روی GitHub Pages

در مخزن به **Settings → Pages** بروید، در بخش *Source* گزینه‌ی **Deploy from a branch** را انتخاب کنید،
شاخه‌ی مورد نظر و پوشه‌ی `/ (root)` را بگذارید و ذخیره کنید. فایل `.nojekyll` از قبل موجود است تا
پوشه‌ی `assets` دست‌نخورده منتشر شود.

## شخصی‌سازی

### ۱. نام و اطلاعات فروشگاه
همه چیز در بالای `assets/js/data.js` در شیء `SHOP` جمع شده است: نام، تلفن، نشانی، اینستاگرام و فهرست شعبه‌ها.
نام فارسی و لاتین در سربرگ و پابرگ صفحات HTML هم آمده که با یک جست‌وجوی «زرّین» و «ZARRIN» قابل تغییر است.

### ۲. محصولات
آرایه‌ی `PRODUCTS` در `assets/js/data.js`. هر قطعه این شکل را دارد:

```js
{ id: 'zr-101', title: 'حلقه تک‌نگین «ستاره»', en: 'Etoile Solitaire',
  cat: 'ring',          // یکی از کلیدهای CATEGORIES
  art: 'ring',          // طرح برداری: ring, necklace, earring, bracelet, bangle, coin, set, pendant
  weight: 3.2,          // گرم
  karat: 18, wage: 18,  // عیار و درصد اجرت
  gem: 'diamond',       // یا null
  metal: 'white', carat: 0.42,
  stock: 4, rating: 4.9, reviews: 128,
  colors: ['white', 'yellow', 'rose'],
  desc: '…' }
```

قیمت خودکار از روی وزن و نرخ روز محاسبه می‌شود؛ نیازی به نوشتن دستی قیمت نیست.
برای قیمت ثابت (مثل سکه) کافی است `fixed` را مقدار بدهید.

### ۳. رنگ‌ها و ظاهر
همه‌ی متغیرها در ابتدای `assets/css/style.css` زیر `:root` هستند: طیف طلایی، رنگ‌های سطح، شعاع گوشه‌ها،
سایه‌ها و منحنی‌های شتاب. پوسته‌ی روشن هم در بلوک `html[data-theme="light"]` تعریف شده است.

### ۴. اتصال نرخ لحظه‌ای واقعی
نرخ‌های پیش‌فرض **نمایشی**‌اند و با نوسان تصادفی کوچکی به‌روز می‌شوند. برای وصل کردن به سرویس واقعی،
پیش از بارگذاری `main.js` این خط را در `<head>` صفحه اضافه کنید:

```html
<script>window.ZARRIN_RATES_API = 'https://api.example.com/gold';</script>
```

پاسخ باید JSON با این کلیدها باشد (مقادیر به تومان):

```json
{ "gram18": 7450000, "gram24": 9930000, "mesghal": 32280000,
  "coinEmami": 82500000, "coinHalf": 44900000, "coinQuarter": 27600000 }
```

سایت هر ۴۵ ثانیه دوباره درخواست می‌دهد و اگر سرویس در دسترس نبود، بی‌صدا به حالت نمایشی برمی‌گردد.

### ۵. فرم تماس و خبرنامه
فرم‌ها در حال حاضر فقط اعتبارسنجی سمت کاربر انجام می‌دهند و چیزی ارسال نمی‌کنند. برای فعال کردن،
در `initForms` داخل `assets/js/main.js` یک `fetch` به سرویس دلخواه (Formspree، یک تابع بدون‌سرور یا API خودتان)
جایگزین پیام موفقیت کنید.

### ۶. سبد خرید و پرداخت
سبد خرید کاملاً سمت کاربر و روی `localStorage` کار می‌کند. دکمه‌ی «تکمیل سفارش» فعلاً فقط پیام تأیید نشان می‌دهد؛
برای اتصال به درگاه، هندلر `#checkout` در `initCartUI` را به API پرداخت خود وصل کنید.

## ساختار پروژه

```
├── index.html            صفحه‌ی نخست
├── products.html         فروشگاه با فیلتر و مرتب‌سازی

├── about.html            درباره‌ی ما
├── contact.html          تماس
├── 404.html
├── manifest.webmanifest  تنظیمات PWA
├── sitemap.xml · robots.txt
├── assets/
│   ├── css/style.css     کل سیستم طراحی
│   └── js/
│       ├── data.js       محصولات، دسته‌ها، نرخ‌ها و فرمول قیمت
│       ├── art.js        تصویرسازی برداری قطعات و آیکون‌ها
│       ├── gl.js         ریاضیات، هندسه و کمک‌کننده‌های WebGL
│       ├── jewel3d.js    نمایشگر سه‌بعدی (شیدرها و حلقه‌ی رندر)
│       └── main.js       منطق سایت
└── docs/benchmark.md     مقایسه با سایت‌های مرجع جهانی
```

## پشتیبانی مرورگر

| قابلیت | پشتیبانی |
|---|---|
| کل سایت | همه‌ی مرورگرهای مدرن (Chrome/Edge ۹۰+، Firefox ۹۰+، Safari ۱۵+) |
| نمایش سه‌بعدی | نیازمند WebGL2؛ در نبود آن خودکار به تصویر برداری جایگزین می‌رود |
| بدون جاوااسکریپت | صفحات و متن‌ها کامل نمایش داده می‌شوند؛ فقط بخش‌های تعاملی غیرفعال‌اند |

## نکته‌ی حقوقی

داده‌های محصولات، نظرات مشتریان، شعبه‌ها و نرخ‌ها همگی **نمونه و ساختگی** هستند و باید پیش از
انتشار واقعی با اطلاعات فروشگاه شما جایگزین شوند. برچسب‌هایی مثل «نماد اعتماد» در پابرگ صرفاً
جای‌نگهدار طراحی‌اند؛ تا زمانی که مجوز واقعی نگرفته‌اید، آن‌ها را نمایش ندهید.
